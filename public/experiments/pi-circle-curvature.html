S¹ᵣ(O) = { x ∈ ℝ² : ||x − O|| = r }
γ(θ) = O + r(cos θ, sin θ),　θ ∈ [0, 2π)
κ = 1/r,　∫ κ ds = (1/r) · 2πr = 2π

內接多邊形用來對照三角形／多邊形內外角：n 邊形內角和是 (n−2)π，外角和固定是 2π。當 n 越大，多邊形越接近圓；外角的離散轉向逐漸變成圓的連續總曲率。
